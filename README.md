# 🐍 Estudos em Python

Meus primeiros passos em Python: exercícios dos fundamentos da linguagem.

Este repositório reúne os códigos que escrevi enquanto aprendia o básico de Python no curso **"Aprendendo Python: Conceitos Básicos"**, da [Asimov Academy](https://asimov.academy/) (concluído em novembro de 2026).

## 📂 Estrutura

```
fundamentos/
├── 01-entrada-e-saida/      → input(), print(), f-strings, conversão de tipos
├── 02-condicionais/         → if/elif/else, operadores de comparação e booleanos
├── 03-sequencias-e-loops/   → listas, tuplas, for, while, break e continue
└── 04-dicionarios/          → pares chave-valor
```

## ▶️ Como executar

Com o [Python 3](https://www.python.org/downloads/) instalado, rode qualquer arquivo pelo terminal:

```bash
python fundamentos/03-sequencias-e-loops/desafio_eleicao.py
```
